XOGAME est un jeu XO qui utilise majoritairement du vanilla JS et est basé sur 4 piliers: 
La manipulation de DOM avec les event listeners pour afficher X dans les cases sur lesquelles ont click.
Une fonction jeu qui vérifie que les cases sont libres avant d'afficher "O" de façon aléatoire.
Des fonctions qui détermine si le joueur à gagner ou perdu en fonction des différentes conditions de victoires
( Dans notre cas gagner se résume à aligner trois "X" horizontalement, verticalement ou en diagonal).
